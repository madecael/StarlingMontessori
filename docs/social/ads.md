# Starling Montessori — Paid Social Ad Set

*Soaring minds. Freeing potential.*

Six paid ad units, each locked to a single real creative from the cataloged asset
banks. The main push is the **Primary Classroom opening August 2026 — twelve inaugural
seats** (four units). Two gentle **Toddler Community** units run alongside, since that
program is enrolling now and has the deepest imagery.

Voice is gentle throughout: we invite, we never push. Gentle scarcity only — "twelve
seats," "reserving now," "intentionally small." No countdown timers, no "last chance,"
no emoji. Sentence case. "Children," not "kids." "Guides," not "teachers."

## How to run this set

**Launch first (cold traffic, the two workhorses):**
- **Ad 1 — Primary 2026: The Seats** (`v_a_15s_9x16.mp4`). Tightest hook, native
  vertical, lowest cost-per-view. This is the primary cold-traffic unit for the
  August 2026 push.
- **Ad 5 — Toddler: First Community** (`IMG_9334.HEIC`). Warmest still image, carries
  the active-enrollment program that already has families and proof. Runs in parallel so
  the account is never dependent on a single message.

**Hold for retargeting / warm audiences:**
- **Ad 3 — Primary 2026: The Three-Year Cycle** (`v_a_30s_9x16.mp4`) — the longer
  continuity story for people who already engaged. Serve in Feed to LP visitors.
- **Ad 2 — Primary 2026: Stand in the Room** (`Dakota & pink Tower.jpg`) and **Ad 4 —
  Primary 2026: The Prepared Environment** (`IMG_6155.HEIC`) are still-image rotations to
  keep the Primary set fresh and combat creative fatigue once the videos have run a while.
- **Ad 6 — Toddler: Real Work** (`IMG_5439.jpg`) — second Toddler still for variety /
  retargeting against Ad 5.

**Test:** if you want a second cold video variant, run **Video C** (`v_c_16s_9x16.mp4`)
as an A/B against Ad 1's 15s cut to see which hook holds attention — same copy, same LP.

Optimize every unit for the **tour / lead** (form submit on the landing page), not reach.
With twelve seats, a handful of qualified tours is the win. Keep budgets modest and
frequency-capped — this is a neighborhood school, not a scale play.

**Landing URLs:** Primary ads → `https://starlingmontessorischool.com/lp/primary-2026`.
Toddler / general ads → `https://starlingmontessorischool.com/open-house`.
